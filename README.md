## Изменение формы и вычисления по осям

`reshape(rows, columns)` меняет форму, сохраняя число элементов. `reshape(-1)` делает массив одномерным.

В матрице `axis=0` означает свёртку строк: останется по одному значению для каждого столбца. `axis=1` означает свёртку столбцов: останется по одному значению для каждой строки.

Пример на других данных:

```python
demo_reshape = np.arange(1, 7).reshape(2, 3)
print(demo_reshape)
print(demo_reshape.sum(axis=0))  # три суммы по столбцам
print(demo_reshape.sum(axis=1))  # две суммы по строкам
```

## Series и DataFrame

`Series` — одномерный набор значений с метками индекса. `DataFrame` — таблица из столбцов. ## Сортировка и фильтрация

Заказы без даты отправки исключите только из этого расчёта; исходную таблицу сохраните.

Подсказка: `(table['end'] - table['start']).dt.days`. Средний срок отправки считайте по заказам, до объединения с позициями.

**Проверка перед сдачей**

- У каждого обязательного задания есть код и видимый результат. Текстовые ответы заполнены там, где они запрошены.

- Массив `a` и исходные CSV сохранены. Третий раздел начинается с повторного чтения исходного каталога.

- Число строк после каждого объединения проверено. Для числа заказов в таблице позиций использован `nunique`, для количества единиц — сумма `quantity`. В исходной таблице `orders` число строк равно числу заказов.

- Выручка рассчитана по ценам позиций с учётом скидки. Промежуточные значения сохранены без округления.

- В `results` есть `catalog_stock.csv`, `country_report.csv`, `top_products.csv`.

- После перезапуска ядра обязательные ячейки выполняются сверху вниз.
